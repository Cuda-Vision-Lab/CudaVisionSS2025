# CudaVision SS2025

This repository contains course material, exercises, and pipelines
for CUDA Vision SS2025.

## Features
- Modular project structure
- GPU-accelerated pipelines
- Clean documentation

## Quick Start
```bash
git clone https://github.com/Cuda-Vision-Lab/CudaVisionSS2025.git
```
